# v1.1.4 - Documentation build fix

`proc-daemon` 1.1.4 fixes the docs.rs build. `signal-hook-async-std` is now an optional dependency, enabled only by the `async-std` feature that uses it. It was a plain Unix dependency, so every Linux and macOS build compiled it and its `async-io` 1.x and `rustix` 0.37 tree whatever the features, and `rustix` 0.37 no longer builds on nightly: every docs.rs build since 1.1.0 failed, even with `async-std` left out of the docs features. Builds without `async-std` no longer pull that tree in; builds with it are unchanged.

```toml
[dependencies]
proc-daemon = "1.1"
```
